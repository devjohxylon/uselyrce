What’s in Usely

Admin panel

Browser dashboard for your server. See who’s online, kick or ban players, send broadcasts, manage wipe countdown, and run RCON commands when you need the console.

Kit builder

Click items from the Console catalog to build kits, set cooldowns and claim limits, then save. Players redeem them in-game through the bot.

Discord bot

Included with every plan. Invite it to your Discord, map roles to permissions (kick, ban, kits, RCON, etc.), and staff sign in with Discord — no shared access keys.

Your URL

Each community gets its own panel address, like astral.usely.dev. Owners use email login; staff use Discord.

Multi-server

Add more than one Nitrado WebRCON endpoint on Pro and Network. Switch which server you’re managing from the panel header.
